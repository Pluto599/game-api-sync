# 成员接入说明

飞书 Wiki 为**唯一权威**接口文档。你只需配置两个环境变量，在 IDE 里主动说「对齐 XX 模块」即可，**无需安装 lark-cli**，也**不会**收到 Bot 自动开的 PR。

## 1. 一次性配置（PowerShell）

```powershell
$env:API_SYNC_BASE = "http://120.27.249.20"
$env:API_SYNC_TOKEN = "ed7484c01552b1d3c271870a4c128bc7e1c0e5b92c732d33"
```

建议写入你的 PowerShell Profile，或各 IDE 项目的环境配置。

## 2. 验证连通

```powershell
$h = @{ Authorization = "Bearer $env:API_SYNC_TOKEN" }
Invoke-RestMethod "$env:API_SYNC_BASE/health"
Invoke-RestMethod -Headers $h "$env:API_SYNC_BASE/api/snapshot/modules"
```

应返回 `ok: True` 和 8 个模块名。

## 3. 文档更新后如何对齐代码

1. 群里若收到「XX 模块文档已更新」通知（后续上线），或你已知飞书文档已改。
2. 在 **client** 或 **server** 仓库切到**你自己要提交的分支**。
3. 确保仓库内有 `.cursor/skills/game-api-sync/SKILL.md`（从 [game-api-sync](https://github.com/Pluto599/game-api-sync) 复制 `.cursor/skills/game-api-sync` 整个目录到本仓 `.cursor/skills/`）。
4. 在 Cursor 中说：

   > 根据最新飞书接口文档，对齐本仓库【战斗】模块的协议代码

5. Agent 会拉 ECS 快照、按 `wiki-registry.yaml` 的 glob 修改**现有**源文件。
6. 你自己 review 后 `git commit` / 开 PR。

## 4. 禁止事项

| 禁止 | 原因 |
|------|------|
| 本机安装 / 运行 `lark-cli` | 拉文档仅 ECS 负责 |
| 新建 `Generated/` 目录 | v2 方案要求就地改现有文件 |
| 依赖 Bot 自动 PR | 已取消，由 IDE 主动对齐 |

## 5. client / server 仓库安装 Skill

在本机 PowerShell（把路径换成你的仓库根目录）：

```powershell
$src = "E:\Desktop\game-api-sync\.cursor\skills\game-api-sync"
$targets = @(
  "D:\path\to\client-repo",
  "D:\path\to\server-repo"
)
foreach ($repo in $targets) {
  $dest = Join-Path $repo ".cursor\skills\game-api-sync"
  New-Item -ItemType Directory -Force -Path (Split-Path $dest) | Out-Null
  Copy-Item -Recurse -Force $src $dest
  Copy-Item -Force "E:\Desktop\game-api-sync\AGENTS.md" (Join-Path $repo "AGENTS.md")
  Write-Host "OK -> $dest"
}
```

`wiki-registry.yaml` 中的 `client_glob` / `server_glob` 需由负责人按真实目录维护；对齐前 Agent 会读取本仓副本或中央仓配置。

## 6. 常见问题

**Q：PowerShell 里 `curl -H` 报错？**  
A：请用 `Invoke-RestMethod -Headers @{ Authorization = "Bearer $env:API_SYNC_TOKEN" }`，或 `curl.exe -H ...`。

**Q：模块名乱码？**  
A：控制台编码问题；API 数据正常，可在 `$env:TEMP\*.json` 用编辑器查看。

**Q：404 snapshot not found？**  
A：联系管理员在 ECS 执行 `python3 /opt/api-sync/scripts/refresh_all_snapshots.py`。
